# React Pizza — ishlaydigan demo

## Ishga tushirish

1. Papkani VS Code'da oching.
2. Terminal 1:
   `npm install`
3. Terminal 1:
   `npm run server`
4. Terminal 2:
   `npm run dev`
5. Brauzerda Vite bergan `http://localhost:5173` manzilini oching.

## Funksiyalar

- Pizza katalogi, kategoriya va sort
- Savat va miqdor boshqaruvi
- Buyurtma modal: Ism / Manzil / Telefon raqam
- Buyurtmalar backendda `db.json` ichida saqlanadi
- Admin panel: Mahsulotlar / Buyurtmalar / Yetkazilganlar
- Mahsulot qo‘shish, tahrirlash, o‘chirish
- Buyurtmani `✓` bilan yetkazilgan deb belgilash
- Admin qidiruvi

Backend: `http://localhost:4000`
Health: `http://localhost:4000/health`
